# =============================================================================
# SEO PRINCIPLES
# =============================================================================

SEO must be considered from the beginning of the project.

Every page should have a clear purpose.

Build semantic, accessible and crawlable websites.

Never sacrifice user experience for SEO.

Prefer long-term best practices over short-term ranking tricks.
# =============================================================================
# TECHNICAL SEO
# =============================================================================

Every project should include:

• Unique page titles.

• Unique meta descriptions.

• Canonical URLs where appropriate.

• Semantic HTML.

• Proper heading hierarchy.

• robots.txt.

• sitemap.xml.

• Open Graph metadata.

• Twitter Card metadata.

Use structured data (Schema.org) when it provides value.

# =============================================================================
# CONTENT & PERFORMANCE
# =============================================================================

Pages should provide meaningful content.

Avoid duplicate content.

Optimize images and media.

Use descriptive alt attributes.

Generate clean, readable URLs.

Keep page loading times low, as performance directly impacts user experience and search visibility.

# =============================================================================
# SEO REVIEW
# =============================================================================

Before completing a project verify:

✓ Every page has a unique title.

✓ Meta descriptions are present.

✓ Heading structure is logical.

✓ Images include alt text.

✓ robots.txt exists.

✓ sitemap.xml exists.

✓ Structured data has been added where appropriate.

✓ URLs are clean and descriptive.

✓ No obvious SEO issues remain.

# =============================================================================
# SUCCESS CRITERIA
# =============================================================================

A project is considered SEO-ready when:

✓ Technical SEO has been implemented.

✓ Metadata is complete.

✓ Semantic HTML is used.

✓ Search engines can crawl the website correctly.

✓ Performance supports a good user experience.

✓ The project is ready for indexing without major technical issues.
