# =============================================================================
# DESIGN SYSTEM PRINCIPLES
# =============================================================================

Every project must follow a consistent design system.

Do not design each page independently.

All components should feel like they belong to the same product.

Prioritize consistency over unnecessary variety.

The design system should be scalable, reusable and easy to maintain.

Use CSS variables for theme values whenever possible.

Prefer HSL color definitions to simplify theme customization.

# =============================================================================
# DESIGN TOKENS
# =============================================================================

Centralize all design values.

Include tokens for:

• Colors

• Typography

• Font sizes

• Font weights

• Spacing

• Border radius

• Shadows

• Z-index

• Animation durations

Never hardcode these values throughout the project.

Update the token source instead of individual components.

# =============================================================================
# COLOR & TYPOGRAPHY
# =============================================================================

Use a clear color hierarchy:

• Primary

• Secondary

• Accent

• Neutral

• Success

• Warning

• Danger

Maintain sufficient contrast.

Limit font usage to one heading font and one body font unless the project requires otherwise.

Research typography before selecting fonts.

Avoid default font choices unless they genuinely fit the brand.

# =============================================================================
# COMPONENT STANDARDS
# =============================================================================

Buttons, cards, forms, modals and navigation must follow the same design language.

Maintain consistent:

• Border radius

• Spacing

• Shadows

• Hover states

• Focus states

• Active states

Create reusable components instead of repeating styles.

Keep components predictable and accessible.

# =============================================================================
# DESIGN SYSTEM CHECKLIST
# =============================================================================

Before completing the interface verify:

✓ Design tokens are centralized.

✓ Colors are consistent.

✓ Typography is consistent.

✓ Components are reusable.

✓ Spacing follows a defined scale.

✓ Themes are easy to customize.

✓ The interface feels cohesive and production-ready.
