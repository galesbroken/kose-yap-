# =============================================================================
# DEPLOYMENT PRINCIPLES
# =============================================================================

Every project must be production-ready.

Do not develop separately for development and production.

Prepare the project for deployment from the beginning.

Keep deployment simple, repeatable and reliable.

Avoid manual deployment steps whenever possible.

# =============================================================================
# PRODUCTION PREPARATION
# =============================================================================

Before deployment:

• Verify all environment variables.

• Remove debug code.

• Remove test files.

• Remove unused assets.

• Verify production configuration.

• Optimize frontend assets.

• Ensure database migrations are ready.

The project should start successfully on a clean server.

# =============================================================================
# DEPLOYMENT CHECKLIST
# =============================================================================

Before deployment verify:

✓ Environment variables configured.

✓ Database initializes correctly.

✓ Automatic migrations work.

✓ Error handling is active.

✓ Logging is enabled.

✓ Security review completed.

✓ Performance review completed.

✓ SEO review completed.

✓ Documentation updated.

✓ No critical issues remain.

# =============================================================================
# POST DEPLOYMENT
# =============================================================================

After deployment verify:

• Application starts successfully.

• Database connection is healthy.

• Logs contain no critical errors.

• Static assets load correctly.

• Forms and authentication work.

• Emails and external services function correctly.

• Performance remains acceptable in production.

Resolve deployment issues before considering the release complete.

# =============================================================================
# SUCCESS CRITERIA
# =============================================================================

A deployment is considered successful when:

✓ The application is stable.

✓ No critical runtime errors exist.

✓ Security checks have passed.

✓ Performance is acceptable.

✓ Monitoring and logging are active.

✓ The project is ready for real users.

Deployment is complete only after production verification has been performed.
