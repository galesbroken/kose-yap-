# =============================================================================
# UI/UX PRINCIPLES
# =============================================================================

Every interface must be intentionally designed.

Research the client's industry, competitors and target audience before designing.

Never reuse the same layout across projects.

Avoid template-like interfaces.

Every project should have its own visual identity while remaining familiar and intuitive.

Design for users, not for trends.

Always balance aesthetics, usability and performance.
# =============================================================================
# LAYOUT & VISUAL HIERARCHY
# =============================================================================

Create clear visual hierarchy using spacing, typography and contrast.

Guide the user's attention naturally.

Keep layouts clean and balanced.

Avoid unnecessary elements.

Use consistent spacing and alignment throughout the project.

Every page should have an obvious primary action.

Prioritize mobile-first responsive design.
# =============================================================================
# COMPONENTS & FORMS
# =============================================================================

Build reusable UI components.

Maintain consistent styles across buttons, cards, forms and navigation.

Forms should request only the information that is necessary.

Provide clear validation and helpful feedback.

Interactive elements should always have hover, active and focus states.

Ensure components remain accessible and responsive.

# =============================================================================
# PREMIUM EXPERIENCE
# =============================================================================

Every project should feel custom-designed.

Research modern premium websites before making major design decisions.

When appropriate, use high-quality interactions, subtle animations and thoughtful micro-interactions.

Avoid excessive visual effects.

Use whitespace, typography and composition to create a premium feeling rather than relying on heavy effects.

Every page should leave a strong first impression.
# =============================================================================
# ACCESSIBILITY & UX CHECKLIST
# =============================================================================

Before completing any interface verify:

✓ Responsive on all common screen sizes.

✓ Keyboard navigation works.

✓ Color contrast is sufficient.

✓ Interactive elements provide feedback.

✓ Typography is readable.

✓ Layout is consistent.

✓ Forms are easy to complete.

✓ Navigation is intuitive.

✓ The interface feels unique, premium and production-ready.

Before designing any page:

Research at least 10 high-quality references from different sources.

Do not copy.

Identify common patterns.

Identify weaknesses.

Combine the strongest ideas into a unique design language that fits the client's brand.

Every project should feel original rather than inspired by a single reference.

# =============================================================================
# DESIGN RESEARCH POLICY
# =============================================================================

Before creating or redesigning any interface:

• Research the client's industry.

• Research local and global competitors.

• Research modern UI trends.

• Research typography and color usage.

• Study premium websites from multiple sources.

Never copy a single reference.

Extract the best ideas from multiple references and create an original design.

If the current design feels generic, redesign it before continuing.

# =============================================================================
# DESIGN CONSISTENCY
# =============================================================================

Every page must belong to the same design system.

Maintain consistency across:

• Typography

• Colors

• Buttons

• Forms

• Cards

• Icons

• Spacing

• Border radius

• Shadows

• Animations

Avoid mixing different design styles within the same project.

Consistency increases trust and perceived quality.

# =============================================================================
# UX SUCCESS CRITERIA
# =============================================================================

A user interface is considered complete only if:

✓ It feels custom-designed.

✓ It matches the client's brand.

✓ It is easy to navigate.

✓ It is fully responsive.

✓ It is accessible.

✓ It performs smoothly.

✓ It avoids template-like layouts.

✓ It creates a strong first impression.

If the interface could reasonably be mistaken for a generic template, redesign it.
