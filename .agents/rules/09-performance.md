# =============================================================================
# PERFORMANCE PRINCIPLES
# =============================================================================

Performance is a core feature.

Optimize from the beginning, not after development.

Every new feature should be evaluated for its impact on:

• Loading time

• Rendering

• JavaScript execution

• Database performance

• Animation smoothness

Never sacrifice performance for unnecessary visual effects.

# =============================================================================
# FRONTEND OPTIMIZATION
# =============================================================================

Optimize all frontend assets.

Prefer:

• WebP or AVIF images.

• Lazy loading for images and videos.

• Minified CSS and JavaScript.

• Optimized fonts.

• Deferred or async scripts when appropriate.

Remove unused CSS, JavaScript and assets before delivery.

# =============================================================================
# BACKEND OPTIMIZATION
# =============================================================================

Keep the backend efficient.

Optimize:

• Database queries.

• Middleware usage.

• API responses.

• Static file serving.

Avoid unnecessary queries.

Avoid repeated calculations.

Cache expensive operations when appropriate.

Monitor slow queries during development.

# =============================================================================
# PERFORMANCE REVIEW
# =============================================================================

Before completing a project:

• Review page loading speed.

• Review animation performance.

• Review database performance.

• Review asset sizes.

• Review unnecessary dependencies.

If performance issues are detected,

optimize them before considering the project complete.

# =============================================================================
# SUCCESS CRITERIA
# =============================================================================

A project is considered performance-ready when:

✓ Assets are optimized.

✓ Images use modern formats where appropriate.

✓ Animations remain smooth.

✓ Database queries are efficient.

✓ Unused resources have been removed.

✓ No obvious performance bottlenecks remain.

Performance should remain a priority throughout the project lifecycle.
