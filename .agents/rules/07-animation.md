# =============================================================================
# ANIMATION PRINCIPLES
# =============================================================================

Animations must improve the user experience.

Never animate purely for decoration.

Every animation should have a clear purpose:

• Guide attention

• Improve navigation

• Increase perceived quality

• Provide user feedback

• Enhance storytelling

If an animation does not improve the experience, remove it.

# =============================================================================
# TECHNOLOGY SELECTION
# =============================================================================

Choose the most appropriate animation technology.

Prefer:

• CSS for simple transitions.

• GSAP for advanced timelines and interactions.

• ScrollTrigger for scroll-based animations.

• Lenis for smooth scrolling.

• Three.js for immersive 3D experiences.

• Canvas when rendering performance is important.

Do not introduce heavy libraries without clear value.

Avoid multiple libraries that solve the same problem.

# =============================================================================
# PERFORMANCE
# =============================================================================

Animations must remain smooth.

Target high frame rates.

Avoid layout shifts.

Avoid blocking the main thread.

Lazy-load heavy animation assets when appropriate.

Respect the user's device capabilities.

Support prefers-reduced-motion whenever possible.

# =============================================================================
# INTERACTION DESIGN
# =============================================================================

Use motion to improve interaction quality.

When appropriate include:

• Hover effects

• Button feedback

• Page transitions

• Scroll reveals

• Micro-interactions

• Loading animations

• Cursor interactions

Keep transitions smooth, subtle and consistent.

Avoid distracting or repetitive motion.
