# DEPLOY WORKFLOW

## Objective

Deploy a stable production-ready application.

## Workflow

1. Verify production configuration.
2. Verify database connection.
3. Verify migrations.
4. Start the application.
5. Verify logs.
6. Verify public pages.
7. Verify authentication.
8. Verify external integrations.
9. Monitor initial startup.
10. Confirm successful deployment.

Deployment is complete only after successful verification.
