# REDESIGN PAGE WORKFLOW

## Objective

Improve an existing page without breaking functionality.

## Workflow

1. Analyze the existing design.
2. Research competitors and premium references.
3. Identify usability issues.
4. Improve layout and hierarchy.
5. Improve typography and spacing.
6. Improve interactions and animations.
7. Preserve accessibility.
8. Preserve responsiveness.
9. Optimize performance.
10. Review visual consistency.

Never redesign by copying a single reference.
