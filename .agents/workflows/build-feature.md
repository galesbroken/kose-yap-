# BUILD FEATURE WORKFLOW

## Objective

Implement new functionality while preserving architecture quality.

## Workflow

1. Analyze the feature requirements.
2. Identify affected modules.
3. Reuse existing components whenever possible.
4. Keep architecture consistent.
5. Implement business logic inside services.
6. Validate input.
7. Handle errors.
8. Update database if required.
9. Update documentation if needed.
10. Verify performance and security before completion.

Never duplicate existing functionality.
