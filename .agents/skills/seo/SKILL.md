# SEO SKILL

## Purpose

Build search engine-friendly websites by applying modern technical SEO and content structure best practices.

---

## SEO Strategy

Consider SEO from the first day of development.

Balance:

- User experience
- Performance
- Accessibility
- Semantic structure
- Crawlability

Never optimize for search engines at the expense of users.

---

## Metadata

Every public page should include:

- Unique title
- Unique meta description
- Canonical URL
- Open Graph tags
- Twitter Card tags

Generate metadata dynamically whenever appropriate.

---

## Semantic HTML

Use semantic elements whenever possible.

Prefer:

- header
- nav
- main
- section
- article
- aside
- footer

Maintain a logical heading hierarchy.

Avoid skipping heading levels unnecessarily.

---

## URLs

Create clean and descriptive URLs.

Avoid:

- Random IDs
- Unnecessary parameters
- Long unreadable paths

Keep URLs meaningful and human-readable.

---

## Images

Optimize every image.

Use:

- WebP or AVIF when appropriate
- Meaningful file names
- Descriptive alt text
- Lazy loading where appropriate

Avoid oversized images.

---

## Structured Data

Implement Schema.org markup when it provides value.

Examples:

- Organization
- Local Business
- Product
- Service
- FAQ
- Breadcrumb
- Article

Only include valid structured data.

---

## Performance & SEO

Performance directly affects SEO.

Review:

- Loading speed
- Layout stability
- Responsive behavior
- Mobile usability

Avoid unnecessary assets that negatively impact page speed.

---

## Armes Recommendations

Every production project should include:

- robots.txt
- sitemap.xml
- Dynamic metadata
- Semantic HTML
- Structured data where applicable
- Optimized images
- Accessible content
- Clean URLs

Technical SEO should be complete before deployment.

---
