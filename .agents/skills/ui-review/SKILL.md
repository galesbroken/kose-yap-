# UI REVIEW SKILL

## Purpose

Review every interface as a senior UI/UX designer and provide honest, actionable improvements before considering the design complete.

---

## First Impression

Evaluate the first 5 seconds.

Ask:

- Does it feel premium?
- Does it create trust?
- Is the purpose immediately clear?
- Is the visual identity memorable?

If the first impression is weak, improve it before continuing.

---

## Layout Review

Review:

- Visual hierarchy
- Spacing
- Alignment
- Grid consistency
- Section balance
- White space

Every section should feel intentional.

---

## Typography Review

Review:

- Font selection
- Font pairing
- Font sizes
- Readability
- Heading hierarchy
- Line height
- Contrast

Avoid generic typography.

Typography should reinforce the brand.

---

## Color Review

Review:

- Brand consistency
- Contrast
- Accessibility
- Visual balance
- Accent usage

Avoid random colors.

Every color should have a purpose.

---

## Component Review

Review:

- Buttons
- Cards
- Forms
- Navigation
- Tables
- Modals

Verify consistency across all components.

Avoid mixed design styles.

---

## User Experience Review

Evaluate:

- Navigation clarity
- User flow
- Call-to-action visibility
- Form usability
- Feedback states
- Error handling

Reduce friction wherever possible.

---

## Mobile Review

Verify:

- Responsive layout
- Touch targets
- Readability
- Navigation
- Performance

Mobile experience must match desktop quality.

---

## Motion Review

Review:

- Animation quality
- Timing
- Consistency
- Smoothness
- Purpose

Motion should enhance the experience, not distract from it.

---

## Premium Evaluation

Determine whether the interface feels:

- Custom-designed
- Modern
- Trustworthy
- Professional
- Memorable

If the design resembles a generic template, redesign the weak sections.

---

## Final Design Audit

Before approving any design verify:

✓ Strong first impression

✓ Premium visual identity

✓ Consistent typography

✓ Balanced spacing

✓ Cohesive components

✓ Responsive design

✓ Accessible interface

✓ Effective CTAs

✓ Smooth interactions

✓ Original appearance

Generate a summary highlighting strengths, weaknesses and recommended improvements before marking the design complete.

Never automatically approve your own design.

Always perform a critical review.

If meaningful improvements are possible,
apply them before presenting the final result.
