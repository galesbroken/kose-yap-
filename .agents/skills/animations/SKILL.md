# ANIMATIONS SKILL

## Purpose

Design meaningful, premium and performance-friendly motion experiences.

---

## Motion Philosophy

Motion should communicate.

Every animation must improve:

- User guidance
- Visual hierarchy
- Brand perception
- User feedback
- Storytelling

Avoid decorative animations without purpose.

---

## Animation Strategy

Before creating animations:

- Analyze user flow.
- Identify important content.
- Decide where motion adds value.
- Keep motion consistent throughout the project.

Avoid animating every element.

---

## Motion Hierarchy

Prioritize animation in:

- Hero sections
- Primary CTAs
- Navigation
- Cards
- Forms
- Page transitions
- Loading states

Use subtle motion for secondary elements.

---

## Timing

Animations should feel responsive.

Keep durations consistent.

Avoid slow interfaces.

Use easing naturally.

Maintain a consistent animation rhythm across the project.

---

## Scroll Experience

Use scroll animations to reveal content naturally.

Avoid excessive parallax.

Avoid long chained animations.

Content should remain easy to read.

---

## Micro Interactions

Enhance user interaction with:

- Hover states
- Focus states
- Button feedback
- Form validation
- Navigation feedback
- Loading indicators

Keep interactions subtle.

---

## Loading Experience

Provide polished loading states.

Use:

- Skeleton screens
- Progressive loading
- Smooth transitions

Avoid blocking users with unnecessary loading animations.

---

## Performance

Keep animation lightweight.

Animate only visible elements.

Destroy unused animations.

Avoid unnecessary repaint and reflow.

Always prioritize responsiveness.

---

## Accessibility

Support reduced motion preferences.

Never make animations mandatory.

Ensure usability without motion.

Avoid flashing or rapid repetitive effects.

---

## Armes Recommendations

Every premium project should include:

- Smooth page entrance
- Scroll reveal animations
- Interactive buttons
- Navigation transitions
- Meaningful loading states
- Subtle hover effects
- Consistent animation timing

Motion should feel elegant and intentional.

---

## Checklist

✓ Motion has a purpose

✓ User flow improved

✓ Timing is consistent

✓ Mobile experience verified

✓ Accessibility respected

✓ Performance optimized

✓ Motion feels premium

✓ No unnecessary animations
