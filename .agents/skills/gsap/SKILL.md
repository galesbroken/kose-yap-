# GSAP SKILL

## Purpose

Create smooth, premium and performance-friendly animations using GSAP.

---

## When To Use GSAP

Use GSAP for:

- Hero animations
- Timeline animations
- Scroll interactions
- Page transitions
- Text animations
- Complex sequencing
- Interactive UI elements

Prefer CSS transitions for simple hover and fade effects.

---

## Timeline

Use timelines for related animations.

Keep animations organized.

Avoid long independent animation chains.

Reuse timelines whenever possible.

---

## Scroll Animations

Use ScrollTrigger when scroll-based animation improves the experience.

Animate elements only once unless repetition is intentional.

Avoid excessive scroll effects.

Respect natural reading flow.

---

## Page Transitions

Transitions should feel smooth.

Avoid delaying navigation unnecessarily.

Keep transition durations reasonable.

Always prioritize responsiveness.

---

## Micro Interactions

Enhance:

- Buttons
- Cards
- Navigation
- Forms
- Modals
- Menus

Animations should provide feedback, not distraction.

---

## Performance

Animate:

- Transform
- Opacity

Avoid animating:

- Width
- Height
- Top
- Left

Minimize layout recalculations.

Destroy unused animations.

Lazy-load animation assets when appropriate.

---

## Accessibility

Support prefers-reduced-motion.

Animations must not block interaction.

Avoid flashing or excessive motion.

Allow users to complete tasks comfortably.

---

## Design Principles

Motion should support storytelling.

Maintain consistent easing and timing.

Avoid random animation styles.

Use subtle motion to create a premium experience.

---

## Armes Recommendations

Use GSAP with:

- ScrollTrigger
- SplitType (when appropriate)
- Lenis (when smooth scrolling adds value)

Keep animation logic modular.

Separate animation code from business logic.

---

## Checklist

✓ Purposeful animations

✓ Smooth performance

✓ Consistent timing

✓ Scroll animations optimized

✓ Accessibility respected

✓ Mobile performance verified

✓ Premium user experience
