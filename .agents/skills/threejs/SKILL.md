# THREE.JS SKILL

## Purpose

Create immersive and high-performance 3D experiences only when they provide real value to the project.

---

## When To Use Three.js

Use Three.js when it improves:

- Brand perception
- Storytelling
- Product presentation
- Interactive experiences
- Landing pages
- Premium hero sections

Do not use Three.js simply because it looks impressive.

If CSS, Canvas or GSAP can achieve the same result with lower complexity, prefer those solutions.

---

## Scene Design

Keep scenes clean.

Focus on one primary visual.

Avoid visual clutter.

Use lighting and composition to guide attention.

Every object should have a purpose.

---

## Performance

Optimize every scene.

Keep polygon count reasonable.

Compress textures.

Lazy-load models and textures.

Dispose unused geometries, materials and textures.

Reduce draw calls whenever possible.

Target smooth rendering on desktop and mobile.

---

## Responsive Experience

Design scenes for different screen sizes.

Adapt camera, lighting and object positioning.

Provide graceful fallbacks for low-performance devices.

Never break usability because of 3D content.

---

## User Interaction

Use interaction only when meaningful.

Examples:

- Mouse movement
- Scroll progression
- Hover effects
- Click interactions
- Camera movement

Avoid interactions that feel confusing or overwhelming.

---

## Accessibility

Respect prefers-reduced-motion.

Provide functional alternatives when WebGL is unavailable.

Ensure core content remains accessible without 3D.

Never make critical functionality depend on Three.js.

---

## Integration

Integrate cleanly with:

- GSAP
- ScrollTrigger
- Lenis
- EJS
- Express

Keep rendering logic isolated from application logic.

Avoid mixing UI code with scene management.

---

## Armes Recommendations

Use Three.js for premium experiences such as:

- Interactive hero sections
- Product showcases
- Background particle systems
- Subtle 3D brand elements
- Interactive demonstrations

Avoid using full-screen 3D throughout an entire website unless the project specifically requires it.

Prioritize elegance, performance and usability over visual complexity.

---

## Checklist

✓ Three.js adds real value

✓ Scene optimized

✓ Mobile tested

✓ Assets optimized

✓ WebGL fallback available

✓ Smooth performance

✓ User experience preserved

✓ Clean integration

✓ No unnecessary complexity
